# Bongakonke Mngadi Portfolio

A modern portfolio website showcasing AI agent systems, full-stack products, live demos, screenshots, and production-grade autonomous workflows.

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Vercel Deployment

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
